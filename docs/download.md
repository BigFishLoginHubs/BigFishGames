# Big Fish Games Download Guide

Downloading a game is usually the first step before installation.

## Before Downloading

Check the following:

- Supported operating system
- Available storage
- Internet connection
- Game requirements
- Account requirements
- Official availability of the game

## General Download Process

1. Locate the desired game through an official or authorized source.
2. Review the game's requirements.
3. Sign in if necessary.
4. Start the download.
5. Wait for the download to finish.
6. Locate the downloaded installer or application.
7. Continue with installation.

## Download Problems

You may experience problems such as:

- Download stops unexpectedly
- Download is very slow
- Download fails
- Installer is incomplete
- Game cannot be located
- Insufficient storage
- Connection problems

## Basic Troubleshooting

If your download fails:

- Check your internet connection.
- Make sure enough storage is available.
- Restart the download.
- Restart your device.
- Check whether the service is experiencing an outage.
- Use an official download source.

## Security

Avoid downloading installers from unofficial file-sharing websites.

Do not disable security software simply to install an unknown file.

If a downloaded file appears suspicious, do not run it.

## After Downloading

Once the download is complete, follow the appropriate [Installation Guide](installation.md).
