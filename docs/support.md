# Big Fish Games Support

This page provides general information about finding support for Big Fish Games.

!!! warning "Independent Resource"
    This website is not the official Big Fish Games support website. For current contact information and account-specific assistance, use official Big Fish Games resources.

## When You May Need Support

Customer support may be useful for:

- Account-access problems
- Purchase issues
- Billing questions
- Subscription problems
- Game activation problems
- Download problems
- Installation problems
- Technical issues
- Missing purchases
- Other service-related questions

## Before Contacting Support

Gather useful information such as:

- Game title
- Device or operating system
- Approximate date of the problem
- Description of the issue
- Relevant order information
- Error message, if applicable

Do not provide unnecessary sensitive information.

## Writing a Support Request

A useful support request should clearly explain:

**Problem:**  
Describe what is happening.

**When it started:**  
Explain when you first noticed the problem.

**Game:**  
Provide the name of the affected game.

**Device:**  
Provide the relevant device or operating-system information.

**Troubleshooting:**  
Explain which troubleshooting steps you have already tried.

## Privacy

Never include passwords, full payment-card numbers, security codes, or other confidential information in a public support request.

## Official Resources

For current support options, policies, and account-specific assistance, users should verify information through the official Big Fish Games website and its official customer-support resources.
