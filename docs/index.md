# 🎯 Popular Help Topics

## 🔐 Activation Problems

If a game is not activating correctly, check that:

- You are using the correct account.
- The game was obtained through an authorized source.
- Your internet connection is working when online activation is required.
- The game installation completed successfully.
- Your device meets the required specifications.
- Available updates have been installed.

# 🛠️ Quick Troubleshooting Checklist

If a Big Fish Games title is not working correctly, try these general steps:

### 1. 🔄 Restart the Game

Close the game completely and launch it again.

### 2. 💻 Restart Your Device

A restart can resolve temporary software problems.

### 3. 🌐 Check Your Connection

If the game requires online access, make sure your internet connection is working properly.

### 4. 💾 Check Storage

Make sure your device has enough available storage.

### 5. 📋 Check Requirements

Confirm that your device meets the game's system requirements.

### 6. 🔄 Check for Updates

Make sure the game and relevant system software are up to date.

### 7. 🧹 Review the Installation

If the game continues to fail, review the installation information and consider reinstalling when appropriate.

### 8. 📩 Contact Official Support

If the problem continues, use the official Big Fish Games support resources.

# 🔒 Safety & Privacy

Your account and payment information should always be protected.

Never publish the following information on a public website:

- 🔐 Passwords
- 💳 Full payment-card numbers
- 🔢 Security codes
- 🔑 Account-recovery codes
- 🎟️ Private activation codes
- 📄 Sensitive personal documents
- 👤 Confidential account information

When requesting assistance, provide only the information necessary to explain your problem.

!!! danger "⚠️ Never Share Sensitive Information"
    Legitimate support should not require you to publish your password, full payment-card number, or private security credentials in a public forum.
